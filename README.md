# 刹那 CMスタジオ

画像とキャッチコピーを入れて、100種類以上のデジタルエフェクトを自由に重ね、縦・横・正方形のCM動画をブラウザだけで書き出せるツールです。インストールもサーバーも不要で、画像はすべて端末の中だけで処理されます。

## できること

- シーンごとに画像・キャッチコピー・サブテキスト・長さを設定
- エフェクトを1つずつON/OFFして、強さを調整しながら重ねがけ
  - グリッチ・デジタル（グリッチ、データモッシュ、ピクセルソート、RGBスプリット、VHSノイズ など）
  - 光・フィルム（ブルーム、ハレーション、ライトリーク、レンズフレア、ゴッドレイ、ネオン発光 など）
  - ブラー、残像（エコー、トレイル、長時間露光、スリットスキャン など）
  - 時間操作（スピードランプ、スローモーション、フリーズフレーム、ストップモーション、ループ など）
  - 歪み・空間（リップル、フィッシュアイ、万華鏡、トンネル、ブラックホール、無限ズーム など）
  - スタイライズ・粒子（ピクセル化、結晶化、ポリゴン化、セルアニメ風、光粒子化 など）
  - 合成（ダブルエクスポージャー、多重露光、クロマキー、フレームインフレーム など）
  - カメラワーク（クラッシュズーム、ドリーズーム、2.5Dパララックス、ドローン風 など）
  - トランジション18種（アッシュディゾルブ、インクディゾルブ、ウィップパン、破砕 など）
- 「全体」と「シーンごと」でエフェクトを使い分け
- 文字の動き5種（キネティックタイポグラフィ、タイプライター、デコード など）と書体4種
- 画面比率 9:16 / 16:9 / 1:1、画質 1080p / 720p
- BGMを入れて書き出し（最後の1秒でフェードアウト）
- MP4で保存（ブラウザによってはWebM）

## 使い方

1. ページを開き、「素材・文字」タブでシーンの画像とコピーを入れます。最初に入っている画像と文章はサンプルです。
2. 「エフェクト」タブで、かける対象（全体 / 各シーン / エンディング）を選び、エフェクトをオンにします。
3. 右上の「動画を書き出す」を押します。動画の長さと同じ時間をかけて録画するので、終わるまでタブを開いたままにしてください。
4. 完了したら「動画を保存」を押します。

## 動作環境

- パソコン版の Chrome / Edge を推奨します（WebGL と MediaRecorder を使います）。
- Safari や スマートフォンでも動きますが、重いエフェクトを重ねると処理が追いつかないことがあります。その場合は画質を「軽量」にしてください。
- エフェクトの設定は、使っているブラウザに保存されます。画像は保存されません。

## 対応していない表現

マッチムーブ、モーショントラッキング、カメラトラッキング、マットペイント、オブジェクト変形、マテリアル変換は、動画素材や3D解析が必要なため入っていません。名前に「〜風」と付いているものは、静止画で再現した近似表現です。

## 手元で動かす

`index.html` をブラウザで開くだけで動きます。1ファイルで完結していて、外部から読み込むのは Google Fonts だけです。
